# 0013: FMG messages

`AdvSys.bnd` holds one FMG message table, `AdvCommon.fmg`: 316 messages in Additional I. The file format is in [0001](0001-initial-findings.md).

## Groups

| IDs | Content |
|---|---|
| 100000, 200000, 500000 | Group titles |
| 300000–303026 | Memory Stick, application box, license and wireless messages |
| 501000–501053 | Options screen: labels, values, help lines, cancel question |
| 501100–501112 | Key guide |
| 501120–501122 | Text history |
| 501130–501138 | Restart and quit questions |
| 501150–501166 | Debug screens (flag list, scene ID, layout) |
| 501170–501175 | Engine system menu: save, load, delete, options, restart, quit |
| 501200 and after | Debug names of script actions |
| 505000–505125 | Errors, save data titles, data check, sleep mode |
| 506000, 506001 | Controls screen title |

## Layout

The strings follow the offset table in index order, with no gaps and no shared offsets. Each string ends with one zero byte. The file is padded to 16 bytes. `internal/fmg` builds the file in the same order and gets the original bytes for both games.

A translated FMG can be longer than the original. `kfa fmg import` builds a new `AdvSys.bnd`; the BND aligns entries to 0x800 bytes. `kfa iso put` needs the new BND to fit the original sectors.

## Tools

| Command | Action |
|---|---|
| `kfa fmg export GAMEDIR OUT.json` | Write each message: `file`, `id`, `ja`, `en` |
| `kfa fmg import GAMEDIR IN.json OUT.bnd` | Write the non-empty `en` values and build `AdvSys.bnd` |

Line breaks are `\n` (one byte, `0x0A`). Markup is the same as in `main.dat` ([0004](0004-text.md)).

An import with no translations gives a byte-identical `AdvSys.bnd`.

## Test result

`translations/kfaI/fmg.json` translates the options and key guide messages. The new `AdvSys.bnd` has the original size. In headless PPSSPP, Start in town opens the system menu, and Down, Down, Circle opens the options screen. The screen shows `Music volume`, `Sound effects` and `Defaults`.

The options header (501001 and 501002) has fixed positions: `Select item` and `Change setting` run past the right edge; `Select` and `Change` fit. The label column ends where the sliders start: `Sound effects` touches the slider, `Effects` fits. The help lines (501030 to 501046) fit one line of about 50 characters.

The test file now translates 180 messages: every message a player can see (Memory Stick, app box, network, options, key guide, system menu, errors, save data titles). The save data detail line (`Play time: ...`, 505025) shows in the PSP save screen; the save title comes from the block name ([0004](0004-text.md#block-header)). The debug screens (501140–501166 except the first three, 501200 and after, 501319–501381) and the group titles stay as they are ([0014](0014-debug-screens.md)). Headless PPSSPP shows the options screen in English: header, labels and help line.

## Screen text from other sources

The system menu (`ロード`, `操作説明`, `環境設定`, `ゲーム終了`) is not in the FMG. It is in `main.dat` ([0004](0004-text.md), kind `menu`).
